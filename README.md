# PDF Compressor Front 📄⚡

Современный, быстрый и стильный веб-интерфейс для оптимизации и сжатия PDF-документов.
Выполнен в строгой и контрастной цветовой гамме: **черный, белый и красный**.

---

## 🎨 Дизайн и стилистика
- **Черный (`#09090b` / `#121217`)**: глубокий темный фон, карточки с эффектом glassmorphism и сеткой.
- **Белый (`#ffffff`)**: контрастная типографика, четкие заголовки и показатели.
- **Красный (`#ef4444` / `#dc2626`)**: акцентные кнопки сжатия, индикаторы степени компрессии, бейджи экономии размера и активные состояния Drag & Drop.

---

## 🚀 Функционал
- **Drag & Drop зона загрузки**: удобный перенос PDF файлов или выбор через проводник (поддержка пакетной загрузки).
- **Пресеты компрессии**:
  - **Extreme** (~75% сжатия, 72 DPI, 45% качество) — максимальное уменьшение для почты и веба.
  - **Recommended** (~50% сжатия, 150 DPI, 75% качество) — баланс четкости и размера.
  - **High Quality** (~25% сжатия, 300 DPI, 90% качество) — минимальное сжатие для печати.
- **Точные настройки (Fine-Tuning)**:
  - Слайдер качества изображений (20% – 95%).
  - Выбор разрешения DPI (72, 150, 300).
  - Удаление метаданных документа (автор, дата, софт).
  - Конвертация в Grayscale (оттенки серого) для сканов.
- **Интерактивный процесс сжатия**: анимация прогресса с отображением этапов оптимизации.
- **Результаты и сравнение**:
  - Карточки с подсчетом сэкономленного места.
  - Визуальная шкала сравнения исходного и сжатого размера.
  - Скачивание отдельного сжатого файла или всех сразу.
- **Тестовый режим (Demo sample)**: возможность мгновенного тестирования в один клик без загрузки своего файла.

---

## 💻 Установка и запуск

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```
   Приложение откроется на `http://localhost:3000`.

3. Сборка для production:
   ```bash
   npm run build
   ```
